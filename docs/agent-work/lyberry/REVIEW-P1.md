## Required corrections in this cycle

Add honest purpose strings. Verify with plutil; camera access must not terminate the iOS app for a missing purpose string.
2. **Image safety before raster decode** — lib/domain/image_inspector.dart calls img.decodeImage before checking width*height. A compressed image can allocate an enormous raster before rejection. Use decoder metadata/header dimensions and frame bounds before pixel allocation; decode only a bounded static frame (reject animation if necessary). Keep JPEG/PNG/WebP support and add a small oversized-header regression plus a valid WebP fixture. This is a concrete imported-image memory risk, so review requires the correction, not just a documented limit.
3. **Photo recovery and duplicate selection** — home_screen.dart sets _noticeShown before async recovery has produced a notice, so the recovery notice is never displayed. editor_screen.dart builds recovered assets in didChangeDependencies without catching invalid images; that can crash the editor. Safely validate/dedupe/cap recovered photos, surface failures without a build-time exception, and notify after async recovery. _addPhoto currently appends the same content-addressed ID twice and makes saving impossible; dedupe with a clear notice. PhotoSource.recoverLostPhotos must surface response.exception. Add real recovery success/bad-image and repeated-pick widget tests (the existing report claims recovery coverage but there is none in the supplied widget cases).
4. **Async navigation lifetime** — EditorScreen._save and DetailScreen._confirmDelete call captured navigator.pop after awaited writes without verifying mounted. If the user backs out during a delayed write, completion pops an unrelated route. Guard mounted (or block pop while saving with a deliberate UI), and safely handle _viewPhoto storage failures. Add a delayed-save/back regression.
5. **Actually immutable content-addressed models** — MediaAsset exposes mutable bytes; MediaItem and LibrarySnapshot expose caller-owned mutable lists despite being described as immutable. Defensively copy and expose read-only views. At repository write boundaries, ensure an asset's digest/MIME/dimensions actually match its bytes (not just syntactically valid fields) so a forged direct asset cannot poison the SHA256 store. Add mutation/invalid-asset rollback tests. Avoid repeated expensive raster decoding by centralizing validation.
